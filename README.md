# Agent profiles

[UCP](https://ucp.dev) agent profiles for the automated tools run by
[Bards & Cards](https://bardsandcards.com). Stores that speak UCP fetch these to
see who is calling and which capabilities the caller supports.

| Profile | Used for |
|---|---|
| [`catalog-reader.json`](https://bardsandcards.github.io/agent-profiles/catalog-reader.json) | Reading supplier catalogs: product search and lookup only. No carts, checkouts or orders. |

The files are served by GitHub Pages from `main`. A profile's URL is its
identity, so add a new file rather than renaming one that is in use.
